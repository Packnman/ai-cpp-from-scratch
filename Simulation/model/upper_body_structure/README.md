# Upper-body structure model

`upper_body.xml` は、骨格と人工筋肉の取付位置を確認し、右手を上げる動作を行う
MuJoCoモデルです。体幹と左腕は固定し、右肩帯と右腕だけを可動化しています。

## 構成

- 胸郭: 楕円体1個（接続先は左右の鎖骨のみ）
- 鎖骨: 左右各1本
- 肩甲骨: 左右各1枚の平面三角形
- 上腕骨、尺骨: 左右各1本
- 背骨: 上部、中部、下部の3本
- 骨盤: 二等辺三角形を底面とする三角錐1個
- 筋経路: 大胸筋、前鋸筋、僧帽筋、広背筋の上・中・下部、三角筋の前・横・後部、
  上腕二頭筋、上腕三頭筋

体幹と左側の骨は固定されています。橙色の球は胸郭―鎖骨、鎖骨―肩甲骨、
肩甲骨―上腕骨、上腕骨―尺骨の接続位置を示します。肩甲骨の外側頂点、鎖骨末端、
上腕骨根元は同じ肩ジョイント座標を共有します。筋は`spatial tendon`で表現し、
起始・停止を名前付き`site`として保持しています。左右それぞれ17本、合計34本です。
右側には肩甲骨回旋、肩3軸、肘の合計5自由度があります。`HumanoidDemo`の筋型
ドライバは右側17本の`spatial tendon`へ非負の引張力だけを加え、右手を上げる姿勢へ
追従させます。関節へ直接トルクは加えません。右三角筋の前・横・後部は、肩外転を
担当する3本の独立した引張アクチュエータです。
上げ姿勢では肩甲骨を上方回旋させ、肘をほぼ伸ばしたまま上腕を鉛直方向へ向けます。

重力は`9.81 m/s^2`、右肩甲骨・上腕骨・尺骨の仮質量はそれぞれ`0.20 kg`、`0.90 kg`、
`0.65 kg`です。筋力上限は現行の関節トルク基準と仮モーメントアームから換算した暫定値
であり、実機可否の最終判定には実アクチュエータの張力、ストローク、速度、取付寸法が
必要です。

骨盤は二等辺三角形の底面を肋骨側へ向け、錐の頂点を下へ向けた三角錐です。
底面後方の底辺中央を、背骨下部の末端と同じ座標に置いて結合しています。

表示対応ビルドがある場合は、次のように単体で確認できます。

```sh
build-viewer/Simulation/humanoid_demo --viewer \
  --model Simulation/model/upper_body_structure/upper_body.xml \
  --command '右手を上げて'
```

Spaceキーで初期姿勢から再実行できます。

色は筋群の識別用です。

| 色 | 筋群 |
|---|---|
| 赤 | 大胸筋 |
| 黄 | 三角筋 |
| 橙 | 前鋸筋 |
| 紫 | 僧帽筋 |
| 青 | 広背筋 |
| 桃 | 上腕二頭筋 |
| 緑 | 上腕三頭筋 |
