  1. body.xml
      - CAD由来のリンク寸法、質量、重心、慣性テンソル
      - 関節軸、可動範囲、初期姿勢
      - collision用と表示用geometryの分離

  2. actuators.xml
      - 実機の減速比、最大トルク、電流制限
      - 筋・腱の取付位置、モーメントアーム、ストローク

  3. sensors.xml
      - 実装済みエンコーダ、IMU、力・接触センサ
      - 取付位置、軸方向、更新周期、ノイズ特性

  4. contact.xml
      - 自己衝突の除外設定
      - 足裏や外装の摩擦・接触パラメータ

  5. assets/
      - CADから軽量化した表示メッシュと衝突メッシュ

  Simulation/model/demo/humanoid_supported.xml はこれらを読み込むデモ用ラッパーなので、基本構造は維持し、実データは humanoid/ 側に集約するのがよいです。

  ただし、いきなり全身を置き換えるより、まず今回動かした右肩・右肘だけを実機値に更新して統合テストを維持し、その後に胴体、脚へ広げるのが次の具体的な一歩です。必要になる入力資料は、CADまたはURDF、各部品の質量・重心・慣
  性、関節原点と軸、可動範囲、アクチュエータ仕様です。
