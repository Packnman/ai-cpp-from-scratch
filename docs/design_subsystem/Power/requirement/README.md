# Power System 要求仕様書

# 1. 目的
本書は、人型ロボットシステムに搭載する Power System が満たすべき要求事項を定義する。

Power System は、ロボット各サブシステムへ必要な電力を安全かつ安定して供給し、電圧、電流、温度等の状態を監視・保護することを目的とする。

# 3. 適用範囲
- 主電源
- 制御系電源
- アクチュエータ電源
- バッテリー
- 電圧監視
- 電流監視
- 過電流保護
- 低電圧保護
- 電源遮断

# 4. 基本要求
- `REQ-PWR-SYS-001` 各サブシステムへ必要な電力を供給可能であること。
- `REQ-PWR-SYS-002` 制御系とアクチュエータ系を必要に応じて分離可能であること。
- `REQ-PWR-SYS-003` 電源状態を監視可能であること。
- `REQ-PWR-SYS-004` 電源異常を上位システムへ通知可能であること。
- `REQ-PWR-SYS-005` 安全上必要な場合に電源遮断可能であること。

# 5. 電圧要求
- `REQ-PWR-VLT-001` 主電源電圧を監視可能であること。
- `REQ-PWR-VLT-002` 制御系電圧を監視可能であること。
- `REQ-PWR-VLT-003` アクチュエータ系電圧を監視可能であること。
- `REQ-PWR-VLT-004` 過電圧を検出可能であること。
- `REQ-PWR-VLT-005` 低電圧を検出可能であること。

# 6. 電流要求
- `REQ-PWR-CUR-001` 必要な系統の電流を監視可能であること。
- `REQ-PWR-CUR-002` 過電流を検出可能であること。
- `REQ-PWR-CUR-003` 過電流発生時に出力制限または遮断可能であること。
- `REQ-PWR-CUR-004` 異常電流を Safety System へ通知可能であること。

# 7. バッテリー要求
- `REQ-PWR-BAT-001` バッテリー状態を監視可能であること。
- `REQ-PWR-BAT-002` 残容量を推定可能であること。
- `REQ-PWR-BAT-003` 低残量状態を上位システムへ通知可能であること。
- `REQ-PWR-BAT-004` 危険な低電圧状態になる前に安全停止へ移行可能であること。

# 8. 保護要求
- `REQ-PWR-SAFE-001` 短絡または過電流に対する保護を有すること。
- `REQ-PWR-SAFE-002` 異常温度を検出可能であること。
- `REQ-PWR-SAFE-003` 電源異常時に危険な再投入を防止可能であること。
- `REQ-PWR-SAFE-004` Emergency Stop に連動して必要な駆動系電源を遮断可能であること。
- `REQ-PWR-SAFE-005` 制御系電源断によって危険なアクチュエータ挙動を発生させないこと。

# 9. 状態通知要求
- `REQ-PWR-STATE-001` Voltage を上位システムへ通知可能であること。
- `REQ-PWR-STATE-002` Current を上位システムへ通知可能であること。
- `REQ-PWR-STATE-003` Battery State を上位システムへ通知可能であること。
- `REQ-PWR-STATE-004` Power Error を上位システムへ通知可能であること。

# 10. 品質要求
- `REQ-PWR-QUAL-001` 電源状態をログへ記録可能であること。
- `REQ-PWR-QUAL-002` 保護機能を個別に試験可能であること。
- `REQ-PWR-QUAL-003` 電源系統および定格値を識別可能であること。
