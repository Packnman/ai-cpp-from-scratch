# CMP-LCK-001 Knee Electromagnetic Lock Component 要求仕様書
# 1. 目的
Knee Jointを常時Motor駆動せず、必要時のみLockするComponent要求を定義する。
# 2. Functional
- Lock
- Release
- State feedback
- fault detection
# 3. Safety
Fail-safe philosophyを明示すること。
Engage可能条件をControl / Safetyから受信できること。
# 4. Mechanical
支持脚荷重を保持できること。
必要保持TorqueはLower Limb Dynamicsから決定する。
