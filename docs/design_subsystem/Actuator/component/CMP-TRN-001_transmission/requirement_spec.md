# CMP-TRN-001 Muscle Transmission Component 要求仕様書
# 1. 目的
BLDC Motor出力を筋肉模倣ActuatorのLinear Force / Tendon Tensionへ変換する機械Transmission要求を定義する。
# 2. Functional
- speed reduction
- force amplification
- stroke generation
- low backlash
- serviceability
# 3. Candidate
- Ball Screw
- Lead Screw
- Cable / Tendon
- Pulley
- Linkage
- Differential
# 4. Safety
Mechanical StopとOverload pathを持つこと。
# 5. Performance
Force / Speed / Stroke / Efficiency / Backdrivabilityを用途別に選択可能であること。
