# CMP-LIN-001 Waist Electric Linear Cylinder Component 要求仕様書
# 1. 目的
PelvisとTorso間のPitch / Rollを生成するElectric Linear Cylinder要求を定義する。
# 2. Functional
- length control
- velocity control
- force/current limit
- position feedback
# 3. Motor
Portescap 22ECT60を初期候補とする。
# 4. Safety
- stroke limit
- overload
- over-temperature
- mechanical stop
# 5. System
左右2本を協調してPitch / Rollを生成すること。
