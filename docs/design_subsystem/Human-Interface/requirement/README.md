# Human Interface System 要求仕様書

# 1. 目的
本書は、人型ロボットシステムに搭載する Human Interface System が満たすべき要求事項を定義する。

Human Interface System は、人間とロボットの間で指示、会話、状態表示、警告および緊急操作を行うためのインタフェースを提供することを目的とする。

# 2. 適用範囲
- 音声入力
- テキスト入力
- 音声応答
- 状態表示
- Error表示
- Warning表示
- Emergency Stop

# 3. 基本要求
- `REQ-HMI-SYS-001` 人間からの入力を受け付け可能であること。
- `REQ-HMI-SYS-002` ロボットから人間へ情報を提示可能であること。
- `REQ-HMI-SYS-003` システム状態を確認可能であること。
- `REQ-HMI-SYS-004` 異常状態を人間へ通知可能であること。
- `REQ-HMI-SYS-005` 緊急停止操作を提供すること。

# 4. 音声入力要求
- `REQ-HMI-VOICE-001` 人間の音声を入力可能であること。
- `REQ-HMI-VOICE-002` 音声入力を Brain System へ渡すことができること。
- `REQ-HMI-VOICE-003` 音声入力開始および終了を識別可能であること。
- `REQ-HMI-VOICE-004` 音声入力機能の異常を通知可能であること。

# 5. テキスト入力要求
- `REQ-HMI-TXT-001` テキストによる指示入力が可能であること。
- `REQ-HMI-TXT-002` テキスト入力を Brain System へ渡すことができること。
- `REQ-HMI-TXT-003` 入力元を必要に応じて識別可能であること。

# 6. 出力要求
- `REQ-HMI-OUT-001` 音声による応答が可能であること。
- `REQ-HMI-OUT-002` テキストによる応答が可能であること。
- `REQ-HMI-OUT-003` ロボットの動作状態を表示可能であること。
- `REQ-HMI-OUT-004` Errorを表示可能であること。
- `REQ-HMI-OUT-005` Warningを表示可能であること。
- `REQ-HMI-OUT-006` 通信状態を表示可能であること。

# 7. Emergency Stop要求
- `REQ-HMI-EST-001` 人間が即座に非常停止操作を実行可能であること。
- `REQ-HMI-EST-002` 非常停止操作を Safety System へ確実に伝達すること。
- `REQ-HMI-EST-003` 非常停止状態を明確に表示すること。
- `REQ-HMI-EST-004` 意図しない操作で非常停止状態から復帰しないこと。

# 8. 操作性要求
- `REQ-HMI-USR-001` 通常操作と緊急操作を区別可能であること。
- `REQ-HMI-USR-002` 重要な警告を通常情報より明確に提示すること。
- `REQ-HMI-USR-003` ロボットが処理中、待機中、異常中等の状態を人間が識別可能であること。

# 9. 品質要求
- `REQ-HMI-QUAL-001` 入出力機能を個別に試験可能であること。
- `REQ-HMI-QUAL-002` HMIイベントを必要に応じてログへ記録可能であること。
- `REQ-HMI-QUAL-003` 新しい入力方式または表示方式を追加可能であること。

# 10. 未確定事項

- 音声入出力デバイス
- 表示デバイス
- Emergency Stop の物理方式
- Remote UI の有無
