# 1. ミッション概要

人間が行う肉体労働の一部または全部を代替・支援可能な人型ロボットを実現すること。
近年、人口減少に伴い、肉体労働への従事者が減少傾向であるところを、外国人労働により補っている現状がある。しかし、問題として、治安の悪化や、伝統的な日本文化の崩壊がある。
これらの解決策として人型ロボットによる肉体労働の実現があげられ、
近年の目覚ましいAI進歩により、人型ロボットの実用化が現実的なものとなった。
そこで、日本の将来と現状の問題改善のため、人型ロボットの実用化を目指す。

# 2. 前提条件

## 2.1 使用環境

* `REQ-PRE-001` 人間と同一または類似した作業空間で使用すること。
* `REQ-PRE-002` 屋内環境での使用を基本とすること。
* `REQ-PRE-003` 電源、通信環境、照明条件等が一定範囲で確保された環境で使用すること。
* `REQ-PRE-004` 作業空間には、人、物体、設備、障害物等が存在する可能性があること。

## 2.2 通信・外部計算環境

* `REQ-PRE-005` 通信環境は一時的に利用できなくなる可能性があること。
* `REQ-PRE-006` 外部サーバまたは外部計算機を利用する構成を許容すること。

## 2.3 ハードウェア特性

* `REQ-PRE-007` センサおよびアクチュエータには、測定誤差、応答遅延、個体差および故障が発生する可能性があること。

## 2.4 安全設計

* `REQ-PRE-008` 安全に関する機能は、人工知能による判断のみに依存しないこと。

# 3. 認識要求

## 3.1 環境認識

* `REQ-PER-001` 周囲の人、物体、設備、障害物および作業環境を認識できること。

## 3.2 言語認識

* `REQ-PER-002` 人間から入力された音声およびテキストを認識・理解できること。

# 4. 対話要求

* `REQ-COM-001` 人間と日常的な会話を行えること。
* `REQ-COM-002` 必要な知識を利用して、特定分野に関する専門的な会話を行えること。

# 5. 行動計画・実行要求

* `REQ-ACT-001` 与えられた目的および現在の環境状態に基づいて行動を計画できること。
* `REQ-ACT-002` 計画した行動をControl SystemおよびActuator Systemを通じて実行できること。
* `REQ-ACT-003` 行動の実行結果および環境変化を認識できること。
* `REQ-ACT-004` 実行結果が目標と一致しない場合、または環境条件が変化した場合、必要に応じて行動を再計画できること。
* `REQ-ACT-005` 日常的な作業に必要な汎用的行動を実行できること。

# 6. 記憶・知識要求

* `REQ-MEM-001` 過去の行動、経験および必要な知識を記憶し、後の判断に利用できること。
* `REQ-MEM-002` 複数のロボット間で、許可された経験または知識を共有できること。

# 7. 自律性要求

* `REQ-AUT-001` 外部通信または外部計算機との接続が失われた場合でも、最低限必要な自律動作を継続できること。
* `REQ-AUT-002` 通信断時に少なくとも安全確保、状態監視、停止または安全状態への移行をロボット単体で実行できること。

# 8. 安全要求

* `REQ-SAFE-001` 人間、周囲環境およびロボット自身に対して危険となる動作を抑制できること。
* `REQ-SAFE-002` 認識、人工知能または行動計画機能に異常が発生した場合でも、安全機能を独立して動作させること。
* `REQ-SAFE-003` センサ異常、アクチュエータ異常、通信異常または電源異常を検出した場合、安全側へ移行できること。

# 9. 拡張・学習要求

* `REQ-EXT-001` 行動原則、制約条件および安全規則を後から追加または変更できること。
* `REQ-EXT-002` 初期状態では汎用的な行動を実行可能とし、専門的な行動能力を後から追加または獲得できること。
* `REQ-EXT-003` 新しい認識機能、行動計画機能、知識およびComponentを追加可能な構成とすること。

# 10. 稼働時間・電力要求

* `REQ-PWR-001` 定常負荷条件において、連続5時間以上動作できること。
* `REQ-PWR-002` 高負荷条件において、連続45分以上動作できること。
* `REQ-PWR-003` 瞬間超高負荷条件において、5秒以上動作を継続できること。
* `REQ-PWR-004` 前項の稼働時間を満たすため、負荷状態に応じた電力制限および電力配分を行えること。

# 11. 機体要求

* `REQ-PHY-001` 実機の身長は170 cm程度を目標とすること。
* `REQ-PHY-002` 実機の総重量は60 kg程度以下を目標とすること。
* `REQ-PHY-003` 人間と類似した作業空間および設備を使用できる人型構造を基本とすること。

# 12. 耐環境要求

* `REQ-ENV-001` 温度、湿度、防塵、防水、振動、衝撃等の耐環境性能は、別途定める設計基準書または一般適用規格に従うこと。
