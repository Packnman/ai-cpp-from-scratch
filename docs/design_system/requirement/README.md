# 1. 前置き

本書は、肉体労働への適用を目的とした人型ロボットシステムの要求事項を定義する。

本書では、システムが満たすべき機能、性能、安全性、インタフェースおよび品質に関する要求を定義する。

具体的なハードウェア構成、ソフトウェア構成、アルゴリズム、通信方式、制御方式等については、本書では原則として規定せず、別途設計仕様書にて定義する。

# 2. 概要

本システムは、人間が行う肉体労働の一部または全部を代替・支援可能な人型ロボットを実現することを目的とする。

ロボットは周囲環境を認識し、人間からの指示を理解し、自身の状態および周囲の状況に応じて行動を計画・実行できること。

また、日常会話および特定分野における専門的な会話を行い、人間との自然な意思疎通が可能であること。

システムは、将来的な機能拡張、学習機能の追加、センサおよびアクチュエータの追加を考慮した構成とすること。

# 3. 前提条件

* `REQ-PRE-001` 人間と同一または類似した作業空間で使用すること
* `REQ-PRE-002` 屋内環境での使用を基本とすること
* `REQ-PRE-003` 電源、通信環境、照明条件等が一定範囲で確保されていること
* `REQ-PRE-004` ロボットが使用する作業空間には、人、物体、障害物等が存在する可能性があること
* `REQ-PRE-005` 通信環境が一時的に利用できなくなる可能性があること
* `REQ-PRE-006` 外部サーバや外部計算機を利用する場合でも、通信断時に最低限の安全動作が可能であること
* `REQ-PRE-007` 使用するセンサおよびアクチュエータには測定誤差、応答遅延、故障等が発生する可能性があること
* `REQ-PRE-008` 全ての判断を人工知能のみに依存せず、安全に関する機能は独立して確保すること

# 7. システム要求

## 7.1 環境認識

* `REQ-SYS-PER-001` 周囲に存在する物体を認識できること
* `REQ-SYS-PER-002` 認識した物体の種類を識別できること
* `REQ-SYS-PER-003` 認識した物体の位置を取得できること
* `REQ-SYS-PER-004` 周囲の空間構造を認識できること
* `REQ-SYS-PER-005` 障害物を認識できること
* `REQ-SYS-PER-006` 人間を認識できること
* `REQ-SYS-PER-007` 自身の位置および姿勢を把握できること
* `REQ-SYS-PER-008` 接触、外力および周囲から加わる力を認識できること

## 7.2 会話

* `REQ-SYS-COM-001` 人間の音声を認識できること
* `REQ-SYS-COM-002` 人間からの指示内容を理解できること
* `REQ-SYS-COM-003` 日常会話が可能であること
* `REQ-SYS-COM-004` 会話の文脈を一定期間保持できること
* `REQ-SYS-COM-005` 特定分野において専門的な会話が可能であること
* `REQ-SYS-COM-006` 不明な指示や曖昧な指示について、必要に応じて確認できること

## 7.3 行動

* `REQ-SYS-ACT-001` 人間から指示された行動を実行できること
* `REQ-SYS-ACT-002` 指示内容を複数の行動へ分解できること
* `REQ-SYS-ACT-003` 周囲環境に応じた行動計画を生成できること
* `REQ-SYS-ACT-004` 行動中に環境が変化した場合、必要に応じて計画を変更できること
* `REQ-SYS-ACT-005` 行動の成功または失敗を認識できること
* `REQ-SYS-ACT-006` 行動失敗時に、安全な代替行動または再計画を行えること

## 7.4 記憶・学習

* `REQ-SYS-MEM-001` 直近の会話、認識結果、行動結果を保持できること
* `REQ-SYS-MEM-002` 必要な情報を長期間保持できること
* `REQ-SYS-MEM-003` 新しい語句、物体、場所等を登録できること
* `REQ-SYS-MEM-004` 過去の行動結果を今後の判断へ利用できること
* `REQ-SYS-MEM-005` 学習によって機能および判断性能を改善可能であること

## 7.5 自律動作

* `REQ-SYS-AUT-001` 外部通信が利用できる場合、外部計算資源を利用可能であること
* `REQ-SYS-AUT-002` 外部通信が利用できない場合でも、最低限の認識、判断および安全動作が可能であること
* `REQ-SYS-AUT-003` 外部システムの異常によって危険な動作を開始しないこと

# 8. 機能・性能要求

## 8.1 認識性能

* `REQ-PER-REC-001` 指定した対象物を実用上必要な精度で認識できること
* `REQ-PER-REC-002` 物体の位置を作業に必要な精度で推定できること
* `REQ-PER-REC-003` 認識結果には信頼度を付与可能であること
* `REQ-PER-REC-004` 信頼度が低い場合に、再認識または追加確認を行えること

## 8.2 会話性能

* `REQ-PER-COM-001` 通常の会話速度で入力された音声を処理できること
* `REQ-PER-COM-002` 発話内容に対して実用上許容可能な時間内に応答できること
* `REQ-PER-COM-003` 過去の会話内容を考慮した応答が可能であること
* `REQ-PER-COM-004` 専門用語、固有名詞および登録済み語句を使用した会話が可能であること

## 8.3 行動計画性能

* `REQ-PER-PLN-001` 目的達成に必要な複数ステップの行動計画を生成できること
* `REQ-PER-PLN-002` 行動中に新たな障害が発生した場合、再計画できること
* `REQ-PER-PLN-003` 実行不可能な行動を可能な範囲で排除できること
* `REQ-PER-PLN-004` 安全制約に違反する計画を実行しないこと

## 8.4 動作性能

* `REQ-PER-MOT-001` 人型ロボットとして必要な姿勢を維持できること
* `REQ-PER-MOT-002` 指定された位置へ移動できること
* `REQ-PER-MOT-003` 物体を把持、移動、設置できること
* `REQ-PER-MOT-004` 人間および周囲物体との不要な衝突を回避できること
* `REQ-PER-MOT-005` 動作中の異常を検知した場合、安全状態へ移行できること

## 8.5 処理性能

* `REQ-PER-PRC-001` 制御に必要な処理周期を満足すること
* `REQ-PER-PRC-002` 認識処理、行動計画処理および制御処理が相互に重大な遅延を発生させないこと
* `REQ-PER-PRC-003` 処理負荷の増加時に安全機能が失われないこと

* `REQ-IF-SEN-002` IMUを接続可能であること
* `REQ-IF-SEN-003` 距離センサを接続可能であること

* `REQ-IF-SEN-005` トルクセンサを接続可能であること
* `REQ-IF-SEN-006` タッチセンサを接続可能であること
* `REQ-IF-SEN-007` 関節角センサを接続可能であること
* `REQ-IF-SEN-008` 温度センサを接続可能であること
* `REQ-IF-SEN-009` 電圧・電流センサを接続可能であること
* `REQ-IF-SEN-010` センサ追加時にシステム全体の大幅な変更を必要としない構成であること

## 9.2 アクチュエータインタフェース

* `REQ-IF-ACT-001` 関節モータを制御可能であること
* `REQ-IF-ACT-002` ハンドを制御可能であること
* `REQ-IF-ACT-003` グリッパを制御可能であること
* `REQ-IF-ACT-004` 移動機構を制御可能であること
* `REQ-IF-ACT-005` その他拡張アクチュエータを追加可能であること

## 9.3 内部通信インタフェース

* `REQ-IF-INT-001` 上位処理系と下位制御系の間で指令および状態情報を送受信できること
* `REQ-IF-INT-002` 通信異常を検出できること
* `REQ-IF-INT-003` 通信断時に安全状態へ移行できること
* `REQ-IF-INT-004` センサ、制御装置および計算装置の交換を考慮した構成であること

## 9.4 外部通信インタフェース

* `REQ-IF-EXT-001` 有線または無線通信により外部計算機と通信可能であること
* `REQ-IF-EXT-002` 外部サーバとの通信状態を監視できること
* `REQ-IF-EXT-003` 通信切断後に自律動作へ移行できること
* `REQ-IF-EXT-004` 通信復旧後に安全に通常動作へ復帰できること

## 9.5 人間とのインタフェース

* `REQ-IF-HMI-001` 音声による指示が可能であること
* `REQ-IF-HMI-002` 必要に応じてテキスト入力が可能であること
* `REQ-IF-HMI-003` ロボットの状態を人間が確認できること
* `REQ-IF-HMI-004` エラーおよび異常内容を通知できること
* `REQ-IF-HMI-005` 緊急停止操作が可能であること

# 10. 安全性要求

## 10.1 基本安全要求

* `REQ-SAFE-BAS-001` 人間へ危害を与える可能性のある動作を可能な限り防止すること
* `REQ-SAFE-BAS-002` システム異常時に安全側へ動作すること
* `REQ-SAFE-BAS-003` 安全機能はAIによる判断のみに依存しないこと
* `REQ-SAFE-BAS-004` 安全に関する制約は通常の行動計画より優先すること

## 10.2 非常停止

* `REQ-SAFE-EST-001` 人間が即座にロボットを停止できる非常停止機能を有すること
* `REQ-SAFE-EST-002` 非常停止時には危険なアクチュエータ出力を停止すること
* `REQ-SAFE-EST-003` 非常停止状態から意図せず自動復帰しないこと

## 10.3 制限機能

* `REQ-SAFE-LIM-001` 関節角度に安全上必要な上限または下限を設定可能であること
* `REQ-SAFE-LIM-002` 関節速度に安全上必要な上限を設定可能であること
* `REQ-SAFE-LIM-003` モータトルクに安全上必要な上限を設定可能であること
* `REQ-SAFE-LIM-004` 接触力に安全上必要な上限を設定可能であること
* `REQ-SAFE-LIM-005` 移動速度に安全上必要な上限を設定可能であること
* `REQ-SAFE-LIM-006` 消費電流に安全上必要な上限を設定可能であること
* `REQ-SAFE-LIM-007` 温度に安全上必要な上限を設定可能であること
* `REQ-SAFE-LIM-008` 電源電圧に安全上必要な上限または下限を設定可能であること

## 10.4 異常検出

* `REQ-SAFE-ERR-001` 通信異常を検出可能であること
* `REQ-SAFE-ERR-002` センサ異常を検出可能であること
* `REQ-SAFE-ERR-003` アクチュエータ異常を検出可能であること
* `REQ-SAFE-ERR-004` 過電流を検出可能であること
* `REQ-SAFE-ERR-005` 過熱を検出可能であること
* `REQ-SAFE-ERR-006` 電源異常を検出可能であること
* `REQ-SAFE-ERR-007` 転倒を検出可能であること
* `REQ-SAFE-ERR-008` 制御不能状態を検出可能であること
* `REQ-SAFE-ERR-009` 計算処理異常を検出可能であること

## 10.5 通信断時

* `REQ-SAFE-NET-001` 外部通信切断時に危険な動作を継続しないこと
* `REQ-SAFE-NET-002` ローカル処理のみで最低限の安全判断が可能であること
* `REQ-SAFE-NET-003` 必要に応じて停止、安全姿勢維持、待機等へ移行すること
