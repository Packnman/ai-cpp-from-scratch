# 固定会話による top-k 切り分け

評価日: 2026-09-13  
モデル: `models/conversation`（既存重みを変更せず使用）

共通条件は `--temperature 0.8 --max-tokens 64 --input-context 0 --seed 123` で、
次の質問を同じ順序で入力した。

1. こんにちは。今日は何をしていましたか？
2. どんな仕事ですか？
3. 好きな食べ物は何ですか？理由も教えてください。
4. 私はカレーが好きです。あなたは？
5. さっき、あなたは何をしていたと言いましたか？

生ログは [top-k-1.log](top-k-1.log) と [top-k-40.log](top-k-40.log) に保存した。
`top-k 1` では候補が一つなので、温度と乱数シードは選択結果を変えない。

| 条件 | END 発生位置 | リセット通知 | 観察 |
|---|---:|---:|---|
| top-k 1 | なし | なし | 第3問に直接答えず、第5問で直前のカレーを回答した |
| top-k 40 | なし | なし | 第2問と第5問で文脈に整合しない回答が出た |

`top-k 1` でも会話破綻が再現したため、この実測ではランダム選択を主要因とは
判断できない。学習データ、全トークン損失という目的関数、またはモデル能力側を
次に検証する。これは一つの既存チェックポイントに対する診断であり、一般性能の
統計的評価ではない。

```sh
BUILD_DIR=/tmp/ai-cpp-quality-build RUN_BUILD=0 \
    OUTPUT_DIR=/tmp/fixed-chat scripts/evaluate_fixed_chat.sh
```
